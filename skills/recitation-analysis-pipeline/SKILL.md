# 國小朗讀競賽文章解構與朗讀指導評析技能規範

本技能專為「國小朗讀比賽指導老師」角色打造，針對競賽篇目進行深度教學級解構評析。

## 一、 文件字型與排版規範（AGENTS.md 全域強制規範）

生成 Word (.docx) 檔案時，**字型大小必須嚴格遵守以下最低標準，不得例外**：

| 文字類型 | 字型大小 | 字型名稱 | 顏色與格式 |
|---------|---------|---------|-----------|
| 封面大標題 | **18pt - 22pt** | 標楷體 | 粗體，深藍色 `#003366` |
| 章節主標題 (H1) | **16pt** | 標楷體 | 粗體，深藍色 `#003366` |
| 小節副標題 (H2) | **14pt** | 標楷體 | 粗體，深紅 `#800000` |
| 正文、表格內文 | **12pt 以上** | 標楷體 | 1.25 倍行高，黑色/灰色 |
| 附註說明、頁尾 | **12pt 以上** | 標楷體 | 粗體或斜體，深綠/紅色 |

*註：程式中定義全域常數 `FONT_NORMAL = Pt(12)`，嚴禁寫入 `Pt(10.5)`、`Pt(10)` 或 `Pt(9)` 等小於 12pt 的數值。*

## 二、 評析內容六大架構

1. **文章篇目與核心資訊**：篇目名稱、適用對象、核心主旨與情感基調。
2. **聲情節奏與語速**：標註 BPM 語速建議（如 BPM 85 - 95）與音色定位（如溫暖懷舊、熱烈歡快、堅毅昂揚）。
3. **表情與肢體儀態建議**：眼神方向、面部表情、站姿與手勢配合。
4. **易錯字音與扣分地雷**：標示易讀錯字音、句尾下墜或拖音地雷。
5. **段落拆解與聲情起伏評析**：針對第一段至尾段，逐段提供原文對照與表達評析重點。
6. **呼吸換氣點與停頓標記原文**：
   - `[大氣]`：1.0 秒深呼吸點（句號處）
   - `[偷氣]`：0.3 秒微呼吸點（逗號/分號處）
   - `|`：0.5 秒語意停頓界線

## 三、 檔案輸出規範

1. **專屬資料夾**：統一放在 `115初賽國小組國朗篇目_朗讀指導評析大全` 目錄中。
2. **檔案命名**：
   - 全彙整檔：`00_115年初賽國小組國朗篇目_30篇完整朗讀指導評析彙整.docx` / `.md`
   - 單篇檔案：`篇01_看野台戲_朗讀指導評析.docx` / `.md` ... `篇30_成功的背後_朗讀指導評析.docx` / `.md`
3. **雙路徑同步**：同時在 `D:\Antigravity\...` 與工作區相對路徑輸出，確保檔案總覽與磁碟搜尋無死角。
