# 篇目 149《山居》國語朗讀比賽指導評析

## 一、 文章篇目與核心資訊
- **篇目名稱**：篇目 149《山居》
- **作者**：徐志摩
- **適用對象**：國小組 / 國中組 朗讀參賽選手與指導老師
- **核心主旨與情感**：溫馨懷舊、深情溫暖與親情懷念
- **建議語速節奏**：BPM 85 - 95
- **音色與聲情定位**：親切溫柔、帶有深情懷念與真摯童心的聲線

## 二、 朗讀教練情感與肢體表達提示
- **面部表情與肢體儀態**：嘴角保持溫和微笑，眼神溫馨專注，講到動情處可略微放緩語速
- **易錯字音與扣分地雷**：注意「重」字讀音（zhòng / chóng）依句意切換；注意「處」字讀音（三聲 chǔ 與 四聲 chù）之精準發音；注意「為」字（wéi / wèi）隨語境強調聲調；控制句尾氣流與聲調，切忌每一句尾音下墜拖長；注意四聲字（去聲）必須發音到位，避免發音偏軟偏平

## 三、 文章段落拆解與聲情起伏評析

### 第 1 段
**【原文】**：作客山中的妙處，尤在你永不須躊躇你的服色與體態；你不妨搖曳著一頭的蓬草，不妨縱容你滿腮的苔蘚；你愛穿甚麼就穿甚麼；扮一個牧童，扮一個漁翁，裝一個農夫，裝一個走江湖的吉卜希，裝一個獵戶；你再不必提心整理你的領結，你儘可以不用領結，給你的頸根與胸膛一半日的自由，你可以拿一條這邊艷色的長巾包在你的頭上，學一個太平軍的頭目，或是拜倫那埃及裝的姿態；但最要緊的是穿上你最舊的舊鞋，別管它模樣不佳，它們是頂可愛的好友，它們承著你的體重，卻不叫你記起你還有一雙腳在你的底下。

**【朗讀評析與表達重點】**：作為文章開篇，語調宜破題沉穩，明確標示出場景與主題（作客山中的妙處，尤在你永不須躊...），語速宜適中，引導聽眾融入情境。

### 第 2 段
**【原文】**：這樣的玩頂好是不要約伴，我竟想嚴格的取締，只許你獨身；因為有了伴多少總得叫你分心，尤其是年輕的女伴。……平常我們從自己家裏走到朋友的家裏，或是我們執事的地方，那無非是在同一個大牢裏從一間獄室移到另一間獄室去，拘束永遠跟著我們，自由永遠尋不到我們；但在這春夏間美秀的山中或鄉間你要是有機會獨身閒逛時，那才是你福星高照的時候，那才是你實際領受，親口嘗味，自由與自在的時候，那才是你肉體與靈魂行動一致的時候。

**【朗讀評析與表達重點】**：本段承接上文推進情節，注意情節轉折與語調起伏，發音清晰，適度加強關鍵動詞與形容詞的重音表現。

### 第 3 段
**【原文】**：朋友們，我們多長一歲年紀，往往只是加重我們頭上的枷，加緊我們腳脛上的鍊，我們見小孩子在草裏、在沙堆裏、在淺水裏打滾作樂，或是看見小貓追牠自己的尾巴，何嘗沒有羨慕的時候，但我們的枷，我們的錶永遠是制定我們行動的上司！所以只有你單身奔赴大自然的懷抱時，像一個裸體的小孩撲入他母親的懷抱時，你纔知道靈魂的愉快是怎樣的，單是活著的快樂是怎樣的，單就呼吸、單就走路、單就張眼看、聳耳聽的幸福是怎樣的。因此你得嚴格的為己，極端的自私，只許你體魄與性靈，與自然同在一個脈搏裏跳動，同在一個音波裏起伏，同在一個神奇的宇宙裏自得。
    我們渾樸的天真是像含羞草似的嬌柔，一經同伴的牴觸，它就捲了起來；但在澄靜的日光下，和風中，它的姿態是自然的，它的生活是無阻礙的。

**【朗讀評析與表達重點】**：此段為全篇總結昇華之處，情感需收束得圓滿飽滿，句尾語氣需沉穩有力，傳達深刻主旨與無盡餘韻。
